# Ассеты

Арт, модели, звук, шрифты. Пайплайн генерации (концепт → 3D → доработка → Godot) будет добавлен после отдельного обсуждения.

## Имена и место
- Латиница, `snake_case`, без пробелов: `broken_sword_diffuse.png`, `anvil.blend`.
- Ассет лежит рядом со сценой, которая его использует (структура папок игры — решение этапа 3).
- Мокапы в `docs/reference/mockups/` — **референс, не утверждённый арт**. В игру не идут.

## Git LFS
- Картинки, модели, звук, видео, шрифты, исходники арта уходят в LFS автоматически по `.gitattributes`.
- Новый тип бинарного файла → добавить расширение в `.gitattributes` отдельной задачей `shared`.
- Файлы больше 100 МБ — только после согласования.
- Бинарники не сливаются: перед правкой напиши в Issue «держу <файл>».

## Происхождение и лицензия — обязательно
Всё, что сгенерировано ИИ или взято со стороны, записывается в `docs/art/asset-log.md` в том же PR:
дата · ассет · источник (инструмент / сток / вручную) · промпт или ссылка · лицензия · кто.
Без записи ассет в игру не попадает — это нужно для публикации в Steam.

## Кто делает ассет
Решается на планировании (grill-me, чек-лист `design.md`): агент сам (простое), модель для арта, генерация 3D или человек.

## Ключи API
Ключи сервисов генерации — только в `.env` или личных настройках. В репозиторий не попадают никогда.
