### Параллакс по слоям из цельной картинки — предметы «отрываются» (#15)
- Почему: дальний слой — весь мокап, вырезанный предмет нарисован и на нём; когда ближний слой сдвигается сильнее, видно предмет и его неподвижную копию. Человек: «надо осматривать комнату, а не двигать предметы».
- Как избежать: слои одной картинки двигай только вместе (камера панорамирует). Настоящий параллакс — только если задний план нарисован без предметов.

### Во встроенном окне редактора не работают Esc и правый клик (#22)
- Почему: по F5 игра шла во встроенном окне Godot (вкладка **Game**), и оно не передавало игре Esc и правый клик; отдельно от редактора всё работало. Человек нашёл это при проверке.
- Как избежать: ввод проверяй в отдельном окне (`"$GODOT_PATH" --path <проект>`); жалоба «не работает клавиша» — сначала спроси, как запущена игра.

### Цвет больше 1 у Polygon2D не осветляет картинку (#42)
- Почему: перегрев клинка делали через `color` у `Polygon2D` с текстурой фона (значения 2.0 и выше) — на экране ничего не менялось.
- Как избежать: свечение или подсветку делай отдельным `Polygon2D` без текстуры с материалом `CanvasItemMaterial` (`blend_mode = Add`) и прозрачностью по силе эффекта.

### Godot переписывает отступы в открытом JSON (#42)
- Почему: `guard_dialogue.json` был открыт во вкладке редактора Godot; по F5 Godot сохраняет открытые файлы и меняет пробелы на табы — в git всплывало «изменение» без смысла.
- Как избежать: JSON с данными не держи открытым в редакторе Godot (правь в VS Code); всплыло такое изменение — **Discard changes**.
