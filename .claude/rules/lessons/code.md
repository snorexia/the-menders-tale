### Переменная цикла `for` без типа — ошибка разбора (#15)
- Почему: в песочницах `untyped_declaration=2` — предупреждение считается ошибкой, и `for name in [...]` не загружается (в том числе во временных скриптах `--script`).
- Как избежать: тип у переменной цикла — `for layer_name: String in names:`, `for i: int in 120:`.
