### Параллакс по слоям из цельной картинки — предметы «отрываются» (#15)
- Почему: дальний слой — весь мокап, вырезанный предмет нарисован и на нём; когда ближний слой сдвигается сильнее, видно предмет и его неподвижную копию. Человек: «надо осматривать комнату, а не двигать предметы».
- Как избежать: слои одной картинки двигай только вместе (камера панорамирует). Настоящий параллакс — только если задний план нарисован без предметов.
