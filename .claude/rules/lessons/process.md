### Агент не может слить PR (#3)
- Почему: авто-режим Claude Code блокирует `gh pr merge` без проверки человеком.
- Как избежать: агент открывает PR и сообщает ссылку; сливает человек (**Squash and merge**).

### Стёрто тело задачи при сбое сети (#3)
- Почему: `gh issue view > файл` упал по таймауту, файл остался пустым, `gh issue edit --body-file` записал пустое тело.
- Как избежать: перед `gh issue edit --body-file` проверять, что файл не пустой (`[ -s файл ]`); при сбое — не повторять запись вслепую.
