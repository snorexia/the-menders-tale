# Инструкции для команды (onboarding)

Действует всегда. Цель — любой участник настраивает ПК и работает по инструкции, не задавая вопросов.

## Когда предлагать инструкцию
- Ты установил, подключил или настроил инструмент, либо изменил настройку, которую придётся повторить **на каждом ПК** → **спроси человека**, нужна ли инструкция, и **сразу предложи черновик**.
- Изменилась настройка, по которой уже есть инструкция → обнови инструкцию в том же PR.
- Новый термин, который участникам может быть непонятен → добавь в `docs/onboarding/glossary.md`.

## Где лежат
- `docs/onboarding/README.md` — с чего начать и порядок.
- `docs/onboarding/NN-<тема>.md` — по одной теме на файл, номер = порядок прохождения.
- Новую инструкцию — добавить в таблицу в `README.md` онбординга.

## Как писать
- **Один шаг — одно действие.** «Нажми **File → Clone repository**», «Введи команду: …».
- Интерфейс называй так, как он подписан в программе (на английском, если программа на английском), выделяй **жирным**.
- Команду — отдельным блоком кода, целиком, чтобы её можно было скопировать.
- После шага — **«Должно получиться:»** что человек увидит, если всё прошло хорошо.
- В конце — **«Частые проблемы»**: симптом → что делать.
- Объясняй простыми словами, без жаргона; термин — ссылкой на словарик.
- Только общее. Никаких личных путей, имён ПК, логинов, ключей. Личное каждый пишет в свой `CLAUDE.local.md`.
- Файл — не больше 250 строк.
