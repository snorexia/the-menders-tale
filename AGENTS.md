# AGENTS.md

Вход для ИИ-агентов, кроме Claude Code (Codex и др.). Правила проекта общие для всех агентов и живут в одном месте — здесь их не дублируем.

## Перед любой работой
1. Прочитай [CLAUDE.md](CLAUDE.md) целиком — стек, флоу, принципы, **индекс правил**.
2. Открой правила из `.claude/rules/`, которые относятся к задаче, по таблице-индексу в CLAUDE.md. Правила с «Когда: всегда» читай всегда. Автоподгрузки у тебя нет — открывай файлы сам.
3. Если есть `CLAUDE.local.md` — прочитай: это личные заметки участника о его ПК.

## Планирование — grill-me
Перед каждой задачей (кроме мелочей) выполни процедуру из `.claude/skills/grill-me/SKILL.md` и чек-лист роли рядом (`dev.md`, `design.md`, `story.md`).
Инструмента с кнопками у тебя может не быть — задавай вопросы **текстом**: один вопрос за раз, 2–4 нумерованных варианта с короткими плюсами и минусами, рекомендуемый — первым с пометкой «(Рекомендуется)», всегда можно ответить своими словами.

## Правки правил
Перед изменением `CLAUDE.md`, `AGENTS.md`, `.claude/rules/` или `.claude/skills/` прочитай `.claude/rules/rules-authoring.md` и делай так же, как Claude: лимит 250 строк, обновить индекс, отдельный PR `shared`.
