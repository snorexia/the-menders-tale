# CLAUDE.md

Главный файл правил для ИИ-агентов (Claude, Codex и др.). Читается первым. Детали — в модульных правилах `.claude/rules/` (индекс ниже). Лимит этого и любого файла правил — 250 строк; как менять правила — `.claude/rules/rules-authoring.md`.

## Проект
**The Mender's Tale** — сюжетная игра про средневековую ремонтную мастерскую для ПК (Steam), 2.5D. Исходная идея — `docs/game/original-brief.md`, визуальный ориентир — `docs/reference/mockups/` (референс, не утверждённый арт).

## Стек
- **Движок** — Godot 4.7.2.
- **Язык** — GDScript, стиль — `.claude/rules/gdscript-style.md`.
- **3D** — Blender (+ MCP for Blender для работы агента); **2D** — Krita.
- **Код и тексты** — VS Code; агенты — Claude Code (код), Codex / GPT (арт).
- **Репозиторий** — GitHub `snorexia/the-menders-tale`, задачи — Issues + доска Projects; бинарники — Git LFS.

> Появилась новая технология или плагин — предложи внести её сюда (отдельной задачей `shared`). Видишь в проекте технологию, которой нет в списке, — спроси человека.

## Этап проекта
Сейчас — **этап 2: сценарий и вектор игры**. Механики, архитектура, структура папок Godot и арт-пайплайн **ещё не решены**.
- Не придумывай механики, архитектуру, лор и персонажей по своей инициативе. Предложения — по просьбе и только как Issue с лейблом `proposal`.
- Этапы и роли — `docs/process/workflow.md`. Где остановились — `docs/process/status.md`.

## Флоу работы
1. **Контекст.** Прочитай `docs/process/status.md`, `CLAUDE.local.md` (если есть — личные заметки участника), основную задачу и правила, относящиеся к ней. Не читай всё подряд — экономь контекст.
2. **Задача.** Любая работа — через Issue. Возьми основную задачу, заведи ИИ-подзадачу — `.claude/rules/tasks.md`.
3. **Планирование.** Скилл **grill-me** (`.claude/skills/grill-me/`) — обязательно перед каждой задачей, кроме мелочей. Итог — в тело ИИ-подзадачи, работа — после одобрения плана.
4. **Работа.** Ветка от `dev`, коммиты, PR в `dev` — `.claude/rules/git-workflow.md`.
5. **Проверка.** PR проверяет и сливает человек.
6. **Конец сессии.** Обнови тело ИИ-подзадачи, оставь комментарий-передачу дел, обнови `docs/process/status.md`. Набил шишку — запиши в `.claude/rules/lessons/`.

## Главные принципы
- **Источник правды** — файлы в `docs/` и `.claude/rules/`. Задача им противоречит — спроси человека, а не выбирай сам.
- **Роли** — design, dev, story; роль задачи — лейбл `role:*`. Работай в рамках роли задачи; файлы другой роли — только по явной просьбе.
- **Одно изменение не ломает всю игру.** Одна сцена, локация, эпизод — отдельный файл или папка. Тексты и данные — отдельно от кода и сцен.
- **Общее меняем отдельно.** Глобальные скрипты, настройки проекта, правила — только отдельной задачей с лейблом `shared`.
- **Договорённости из чата** переноси в `docs/`, правила или Issue — иначе их не существует.
- **Повторяющиеся операции** (Blender, Godot, Git) — скриптом в `tools/`; сначала проверь `tools/README.md`.
- **Пути** — только относительные от корня репозитория. Личное — только в `CLAUDE.local.md` (в `.gitignore`).
- **Настроил инструмент** — предложи инструкцию для команды: `.claude/rules/onboarding.md`.
- **Объясняй простым языком.** Команда учится вместе с агентом: термины расшифровывай, у вариантов — плюсы и минусы.

## Индекс правил `.claude/rules/`
Claude Code подгружает правило сам по путям из колонки «Когда»; Codex и другие агенты — открывают нужные по этой таблице. **Добавил или переименовал правило — обнови таблицу в том же PR.**

| Файл | Когда | О чём |
|---|---|---|
| `git-workflow.md` | всегда | Ветки `dev`/`main`, имена веток, коммиты, PR, LFS, бинарники |
| `tasks.md` | всегда | Основные задачи и ИИ-подзадачи, тело как источник правды, передача дел, когда делить задачу, статусы доски |
| `onboarding.md` | всегда | Когда предлагать инструкцию для команды и как её писать |
| `rules-authoring.md` | `.claude/**`, `CLAUDE.md`, `AGENTS.md` | Как писать правила: лимит 250 строк, `paths`, индекс, набитые шишки |
| `gdscript-style.md` | `**/*.gd` | Именование, порядок в файле, типизация, `not`, guard-return, сигналы, форматирование |
| `assets.md` | ассеты, `docs/art/**`, `docs/reference/**` | Имена, LFS, журнал ассетов и лицензии, ключи API |
| `lessons/process.md` | всегда | Набитые шишки: процесс |
| `lessons/code.md` | `**/*.gd`, `**/*.tscn`, `**/*.tres` | Набитые шишки: код |
| `lessons/story.md` | `docs/game/**`, `docs/story/**` | Набитые шишки: сюжет |
| `lessons/design.md` | ассеты, `docs/art/**` | Набитые шишки: арт |
