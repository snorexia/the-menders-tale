# Генераторы 3D: сравнение

Ресерч для задачи #10. Проверено **2026-10-27**. Цены и условия меняются — перед покупкой сверить с официальной страницей.

## Что важно для нас
- **Что генерируем:** только предметы для ремонта (мечи, сумки, доспехи и т.д.) — они 3D и показываются крупно. Сцены — 2D-картинки, генератор 3D для них не нужен (предложение дизайнера, решение 8 в #11 — согласовать в PR).
- **Лицензия:** игру продаём в Steam по всему миру, включая ЕС. Нужна коммерческая лицензия без ограничений по странам.
- **Цена:** бесплатная проба, недорогой платный тариф.
- **Связка с Blender MCP:** Meshy, Hyper3D Rodin и Hunyuan встроены в наш аддон (галочки в панели **MCP for Blender**).
- **Steam:** ИИ-контент в игре раскрывается в анкете Steam (раздел AI Generated Content Disclosure на странице игры). Источник для анкеты — `docs/art/asset-log.md`.

## Рекомендация
1. **Meshy — основной кандидат.** Дешёвый Pro, есть API и MCP, встроен в аддон. Бесплатный тариф годится даже для игры, но с атрибуцией.
2. **Rodin** — если по качеству сетки заметно лучше Meshy. Дороже, API только на дорогом тарифе.
3. **Tripo** — запасной вариант, сравнить на пробе.

## Проба
Цель — сравнить качество на одном предмете. Результаты пробы **в игру не идут**.
- **Предмет:** длинный меч (Longsword) из мокапов `docs/reference/mockups/02-forge-overview.png` и `03-forge-minigame-straighten.png`. Меч — главный тип предмета для ремонта, а тонкий клинок и гарда — сложный случай для генераторов.
- **Картинка:** меч один, целый (не сломанный), на светлом однотонном фоне, сбоку или в три четверти. Вырезать из мокапа в Krita или попросить Codex/GPT нарисовать по мокапу.
- **Где:** Meshy, Rodin, Tripo — бесплатные тарифы, режим **Image to 3D**.
- **Что сравнить:** похожа ли форма, чистая ли сетка (количество полигонов, дыры), качество текстуры, сколько времени ушло.
- **Что прислать агенту:** скриншоты из каждого сервиса и число полигонов, если сервис его показывает. Скачанный файл, если есть, положить локально — в репозиторий не коммитить.

Итог пробы и выбор — в ИИ-подзадаче #11 и в этом файле.
