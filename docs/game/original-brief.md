# Исходный бриф (2026-10-25)

Первое описание идеи от команды, почти дословно. Это исходник идеи, а не утверждённый дизайн: сценарий, механики и архитектура определяются на следующих этапах (см. `docs/process/workflow.md`).

## Идея
Игра типа *Repair this!*: у нас прилавок, к нам приходят люди, и мы им чиним вещи. Действие — в Средневековье: приносят мечи, что-то подшить, разное всякое.

- Главный экран: приходят люди и приносят вещи.
- Кнопка инвентаря.
- Кнопка почты — вызвать курьера, чтобы он принёс недостающие для починки предметы.
- Разные участки для ремонта:
  - стрелка влево — кузня: ремонтируем доспехи и оружие;
  - стрелка вправо — верстак: подшиваем, ремонтируем мелкие штуки.

Сюжет будет дорабатываться и меняться, но ориентир и интерфейс — такие. Визуально — как на мокапах в `docs/reference/mockups/`: где-то 2D, где-то 3D, то есть 2.5D.

## Платформа
ПК, Steam. Возможно позже мобильные и другие платформы.

## Команда
Три человека: дизайнер, разработчик, сценарист. Обязанностями будем меняться — важно не конфликтовать при работе с репозиторием. Работаем с разных ПК, всё создаётся через Claude.

## Что нужно от инфраструктуры
- Удобное место для задач, общения по задачам и понимания прогресса — GitHub Issues + Projects.
- Не конфликтовать при выкатке изменений — Git + Git LFS, ветки, pull request'ы.
- Хранить в репозитории контекст игры, правила для ИИ и ИИ-агентов, правила работы с инструментами, сохранённые скрипты (для экономии токенов).
- Контекст должен легко читаться и правиться людьми и при этом быть понятен ИИ.
- Возможность в любой момент посмотреть, что сделано, открыть модели и поправить руками — каждому со своего ПК.
- Инструменты для генерации моделей и разработки игры.

## Инструменты (выбраны)
| Приложение | Для чего | Кому |
|---|---|---|
| Godot Engine | Сцены, интерфейс, механики, запуск игры | Всем троим |
| GitHub Desktop | Получать общую версию и отправлять изменения | Всем троим |
| Git for Windows (+ LFS) | Версии из терминала, работа через Claude | Всем троим |
| Blender | Модели, материалы, анимации | Дизайнеру и разработчику |
| Krita | Фоны, портреты, иконки, текстуры | Дизайнеру |
| VS Code | Код, сюжетные тексты, описания, документация | Разработчику и сценаристу |
| Discord или Telegram (один общий) | Обсуждения, созвоны, показ экрана | Всем |
| Meshy | Генерация 3D-моделей, когда понадобится | Дизайнеру |
| GitHub Issues + Projects | Задачи, обсуждения, очередь проверки | Всем, через браузер |
