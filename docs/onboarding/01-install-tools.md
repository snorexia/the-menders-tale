# 1. Установка программ

Все программы бесплатные. Устанавливай с официальных сайтов. Где не сказано иначе — в установщике оставляй настройки по умолчанию и нажимай **Next**.

## Всем

### Git for Windows (с Git LFS)
Git — программа, которая хранит историю изменений. Git LFS — дополнение для больших файлов (картинки, модели).
1. Открой https://git-scm.com/download/win и скачай установщик (**64-bit Git for Windows Setup**).
2. Запусти. На экране **Select Components** проверь, что стоит галочка **Git LFS (Large File Support)** (стоит по умолчанию).
3. Дальше — **Next** до конца, затем **Install** и **Finish**.

**Должно получиться:** в меню «Пуск» есть **Git Bash**.

### GitHub Desktop
Программа, чтобы скачивать и отправлять изменения без терминала.
1. Открой https://desktop.github.com и нажми **Download for Windows**.
2. Запусти установщик — он поставится сам и откроется. Входить пока не нужно — это в следующей инструкции.

### GitHub CLI (`gh`)
Нужен, чтобы Claude мог работать с задачами и PR.
1. Нажми **Пуск**, введи `PowerShell`, открой **Windows PowerShell**.
2. Введи команду и нажми Enter:
   ```
   winget install --id GitHub.cli
   ```
3. Если спросит про соглашение — введи `Y` и Enter.
4. **Закрой PowerShell** — новые программы видны только в новом окне.

**Должно получиться:** в новом окне PowerShell команда `gh --version` показывает версию.

### Godot 4.7.2
Игровой движок. Нужна **обычная** версия (не .NET).
1. Открой https://godotengine.org/download/windows и скачай **Godot Engine** версии **4.7.2** (не «.NET»).
2. Это zip-архив без установщика. Распакуй его в удобную папку (например, «Программы» или на рабочий стол).
3. Запускай файл `Godot_v4.7.2-stable_win64.exe`. Можно сделать ярлык: правый клик → **Отправить** → **Рабочий стол (создать ярлык)**.

**Должно получиться:** открывается окно Project Manager. Проект игры пока не создан — это этап 3.

### VS Code
Редактор кода и текстов.
1. Открой https://code.visualstudio.com и нажми **Download for Windows**.
2. В установщике на экране **Select Additional Tasks** поставь галочку **Add "Open with Code" action…** для файлов и папок — удобно.

## Дизайнеру и разработчику

### Blender
1. Открой https://www.blender.org/download/ и скачай установщик для Windows.
2. Установи с настройками по умолчанию.
3. Подключение Blender к Claude — в [04-blender-mcp.md](04-blender-mcp.md).

### Krita (дизайнеру)
1. Открой https://krita.org/en/download/ и скачай **Windows Installer**.
2. Установи с настройками по умолчанию.

## Общение
Установи Discord или Telegram — какой выбрала команда.

## Частые проблемы
- **`winget` не найден** → обнови **App Installer** в Microsoft Store или скачай `gh` с https://cli.github.com (кнопка **Download for Windows**).
- **`gh --version` не работает сразу после установки** → закрой все окна PowerShell и открой новое. Не помогло — перезагрузи ПК.
- **Godot не запускается, ругается на видеокарту** → обнови драйвер видеокарты с сайта производителя.
