# 3. Claude Code: настройка и как давать задачи

Claude Code — ИИ-агент, который работает прямо с файлами проекта: пишет код и тексты, заводит задачи, открывает PR. Правила для него уже лежат в репозитории (`CLAUDE.md`, `.claude/`) — он читает их сам.

## Шаг 1. Установить
1. Открой https://claude.ai/download и скачай приложение **Claude** для Windows.
2. Установи и войди в свой аккаунт Claude (нужна подписка Pro или Max).
3. В приложении открой вкладку **Code**.

## Шаг 2. Открыть проект
1. Во вкладке **Code** начни новую сессию и выбери **папку проекта** — ту, куда клонировал репозиторий в [02-github.md](02-github.md).
2. Первое сообщение для проверки:
   ```
   Прочитай CLAUDE.md и docs/process/status.md и коротко скажи, где мы остановились.
   ```

**Должно получиться:** Claude пересказывает текущий этап и следующие шаги.

## Шаг 3. Личные заметки — `CLAUDE.local.md`
В этот файл пишется всё личное про твой ПК: путь к проекту, где лежат программы, особенности настройки. Он в `.gitignore` — в репозиторий **не попадает**, у каждого свой.
1. Попроси Claude:
   ```
   Создай мне CLAUDE.local.md: проверь, какие программы из docs/process/tools.md у меня установлены, и запиши пути и версии.
   ```
2. Claude спросит разрешение на команды — разреши.

**Должно получиться:** в корне проекта появился `CLAUDE.local.md`, а в GitHub Desktop на вкладке **Changes** он **не** виден (так и надо).

## Шаг 4. Как давать задачи
Любая работа — через задачу на доске. Хороший запрос:
```
Возьми задачу #7.
```
Дальше Claude:
1. Читает задачу и правила по ней.
2. Заводит **ИИ-подзадачу** внутри твоей задачи — там будет всё, что он прочитал, решил и сделал. Её можно открыть на GitHub и проверить.
3. Проводит **grill-me** — задаёт вопросы по одному, с вариантами ответа. Рекомендуемый вариант — первый. Можно выбрать вариант, написать свой ответ («Другое») или попросить: «объясни плюсы и минусы».
4. Показывает план. Работа начинается, только когда ты его одобришь.
5. Делает работу в отдельной ветке и открывает **PR** в `dev`.
6. Ты проверяешь и сливаешь PR — см. [05-daily-workflow.md](05-daily-workflow.md).

Задачи ещё нет? Скажи: «Заведи задачу: <что нужно>, роль <design / dev / story>». Claude оформит её по шаблону.

## Полезные фразы
- «Продолжи задачу #7» — новый чат подхватит работу по ИИ-подзадаче.
- «Хватит вопросов, составляй план» — закончить grill-me.
- «Объясни проще» / «Что это значит?» — Claude обязан объяснять простым языком.
- «Запиши это как шишку» — ошибка попадёт в `.claude/rules/lessons/`, и агенты её больше не повторят.

## Частые проблемы
- **Claude не видит задачи / доску** → не выполнен вход в `gh` ([02-github.md](02-github.md), шаг 6).
- **Claude пишет, что не может слить PR** → так и задумано: сливает человек.
- **Claude работает в `main`** → скажи ему «работаем в dev» — правила это требуют; запиши это как шишку.
