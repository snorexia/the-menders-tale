# 4. Подключить Blender к Claude (MCP)

MCP — способ подключить программу к ИИ. После настройки Claude сможет смотреть сцену Blender, создавать и менять объекты, импортировать модели.

Связка состоит из **двух половинок одного проекта** — *MCP for Blender* (автор ahujasid):
- **аддон** внутри Blender — принимает команды на порту 9876;
- **сервер** для Claude Code — передаёт команды от Claude в аддон.

> Важно: существует ещё **официальный Blender Lab MCP** с похожим названием. С нашим аддоном он **не работает** (запросы зависают). Не смешивай их.

## Шаг 1. Аддон в Blender
1. Открой https://github.com/ahujasid/blender-mcp, найди в списке файлов `addon.py`, открой его и нажми кнопку **Download raw file** (стрелка вниз справа сверху).
2. В Blender: **Edit → Preferences → Add-ons**.
3. Справа сверху нажми стрелку **▾** → **Install from Disk…** и выбери скачанный `addon.py`.
4. Поставь галочку у **Interface: MCP for Blender**. Закрой окно настроек.

## Шаг 2. Запустить сервер в Blender
1. Наведи мышь на 3D-окно и нажми **N** — справа откроется боковая панель.
2. Открой вкладку **MCP for Blender** и запусти сервер кнопкой в этой вкладке.

Сервер нужно запускать при каждом открытии Blender, когда хочешь работать с Claude.

## Шаг 3. Установить сервер для Claude Code
1. Открой **Windows PowerShell** и установи `uv` (менеджер Python-программ):
   ```
   winget install --id astral-sh.uv
   ```
2. **Закрой PowerShell и открой новый**, затем:
   ```
   uv tool install blender-mcp
   ```

**Должно получиться:** в конце `Installed 1 executable: blender-mcp`.

## Шаг 4. Прописать сервер в Claude Code
Проще всего попросить самого Claude. Напиши ему:
```
Пропиши Blender MCP в мои настройки Claude Code по docs/onboarding/04-blender-mcp.md, шаг 4: сервер blender, команда — blender-mcp.exe из папки инструментов uv (uv tool dir --bin). Запиши результат в мой CLAUDE.local.md.
```
Claude добавит в личный файл настроек (`.claude.json` в папке пользователя) запись `mcpServers.blender`. Это личная настройка — в репозиторий она не попадает.

Затем **полностью перезапусти приложение Claude**.

## Шаг 5. Проверить
1. Blender открыт, сервер в нём запущен (шаг 2).
2. Напиши Claude: `Покажи, что сейчас в сцене Blender.`

**Должно получиться:** Claude перечисляет объекты сцены (в новой сцене — Cube, Light, Camera).

## Частые проблемы
- **Claude не видит инструментов Blender** → не перезапущено приложение после шага 4 или не выполнен шаг 4.
- **Запрос к Blender висит и не отвечает** → работает официальный Blender Lab MCP вместо нашего. В приложении Claude: **Settings → Extensions**, отключи расширение Blender (официальное), оставь только наш сервер `blender`.
- **«Cannot connect to Blender»** → в Blender не запущен сервер (шаг 2) или Blender закрыт.
- **`uv` не найден** → закрой все окна PowerShell и открой новое; не помогло — перезагрузи ПК.
- **Сервер отправляет статистику автору** → у сервера есть телеметрия; попроси Claude: «Отключи телеметрию Blender MCP».
