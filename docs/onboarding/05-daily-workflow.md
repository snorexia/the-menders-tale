# 5. Каждый день: задача → план → PR

## Начало работы
1. Открой **GitHub Desktop**, проверь, что вверху **Current branch: dev**.
2. Нажми **Fetch origin**, затем **Pull origin** (если кнопка появилась). Так у тебя будут последние изменения команды.
3. Открой доску задач: https://github.com/users/snorexia/projects/2

## Взять задачу
1. На доске выбери карточку в колонке **К работе** с твоей ролью.
2. Открой Claude Code в папке проекта и напиши: `Возьми задачу #<номер>`.
3. Claude назначит тебя, перенесёт карточку в **В работе** и заведёт ИИ-подзадачу.

## Планирование — grill-me
- Claude задаёт вопросы по одному. Рекомендуемый вариант — первый.
- Не уверен — попроси «объясни плюсы и минусы».
- В конце Claude покажет план. Проверь и одобри — только после этого начнётся работа.
- Итог планирования лежит в ИИ-подзадаче: открой основную задачу на GitHub → блок **Sub-issues** → задача с `[ИИ]`.

## Работа
- Claude работает в отдельной ветке и сохраняет изменения коммитами.
- Прервался — ничего страшного. В новом чате напиши `Продолжи задачу #<номер>`: Claude прочитает ИИ-подзадачу и продолжит.
- Появилась другая работа (нужна иконка, новая механика) — Claude спросит, завести ли отдельную задачу. Не смешиваем роли в одной задаче.

## Проверить и слить PR
Когда работа готова, Claude откроет **PR** (запрос на слияние) в `dev` и пришлёт ссылку. Карточка переедет в **На проверке**.
1. Открой ссылку на PR.
2. Вкладка **Files changed** — что изменилось: красное удалено, зелёное добавлено. Можно навести на строку и нажать **+**, чтобы оставить комментарий.
3. Есть замечания — напиши их в PR или Claude в чат: «Исправь по комментариям в PR».
4. Всё хорошо: **Review changes → Approve → Submit review** (если проверяешь чужой PR).
5. Внизу у зелёной кнопки нажми стрелку **▾**, выбери **Squash and merge**, затем **Confirm squash and merge**.
6. Нажми **Delete branch**.
7. В GitHub Desktop: **Fetch origin → Pull origin**, чтобы забрать слитые изменения.

**Должно получиться:** PR в статусе **Merged**, задачи закрылись, карточка — в **Готово**.

## Бинарные файлы
Сцены Godot, `.blend`, `.kra` не сливаются, если двое правили одновременно. Перед правкой такого файла напиши в задаче: «держу <файл>». Закончил — «отпустил <файл>».

## Конец работы
- Скажи Claude: «Заканчиваем на сегодня» — он обновит ИИ-подзадачу и `docs/process/status.md`.
- Изменения, которые ещё не в PR, Claude отправит в ветку задачи (**push**), чтобы они не потерялись.

## Частые проблемы
- **Конфликт при слиянии PR** (GitHub пишет *This branch has conflicts*) → напиши Claude: «В PR конфликт, разреши». Сам ничего не удаляй.
- **GitHub Desktop показывает изменения, которых ты не делал** → не коммить их; спроси Claude, что это за файлы.
- **Слил по ошибке не через Squash** → ничего страшного, история просто длиннее. В следующий раз выбери Squash.
- **Карточка не переехала в «Готово»** → перетащи её вручную на доске.
