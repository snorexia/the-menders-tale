# 7. Инструменты для работы Claude с Godot

После настройки Claude сможет сам запускать проект Godot, читать ошибки, делать скриншоты сцен и проверять стиль кода. Нужно разработчику; остальным — если хотят, чтобы Claude открывал у них Godot-проект.

Что поставим:
- **Python** — язык для вспомогательных программ (проверка стиля кода).
- **Node.js** — среда, на которой работает [MCP](glossary.md)-сервер Godot.
- **gdtoolkit** — проверка (`gdlint`) и форматирование (`gdformat`) кода GDScript.
- **MCP-сервер Godot** — подключение Godot к Claude. Сам сервер уже прописан в репозитории (`.mcp.json`), тебе нужно только указать, где лежит Godot.

## Шаг 1. Godot
1. Проверь, что у тебя Godot **4.7.2** (из [01-install-tools.md](01-install-tools.md)). Это два файла: `Godot_v4.7.2-stable_win64.exe` и `Godot_v4.7.2-stable_win64_console.exe`.
2. Запомни папку, где они лежат.

**Должно получиться:** ты знаешь полный путь к `Godot_v4.7.2-stable_win64_console.exe`, например `C:\Tools\Godot\Godot_v4.7.2-stable_win64_console.exe`.

Нужна именно версия `_console`: она пишет ошибки текстом, и Claude их видит.

## Шаг 2. Переменная GODOT_PATH
Переменная окружения — именованная настройка Windows, которую читают программы. MCP-сервер берёт из `GODOT_PATH` путь к Godot.
1. Нажми **Win**, введи `переменные` → **«Изменение переменных среды для своей учётной записи»**.
2. В верхнем блоке нажми **«Создать…»**.
3. **Имя переменной:** `GODOT_PATH`. **Значение:** полный путь из шага 1 (к `_console.exe`).
4. **OK** во всех окнах.

**Должно получиться:** в верхнем списке есть `GODOT_PATH` с путём к Godot.

## Шаг 3. Python
Проверь, есть ли Python: открой **Windows PowerShell** и введи:
```
py --version
```
Если видишь `Python 3.14` или новее — переходи к пункту 3. Если нет — сначала пункт 1.

1. Установи Python:
   ```
   winget install --id Python.Python.3.14 -e
   ```
2. Закрой PowerShell.
3. Выключи заглушку Microsoft Store: **Win + I** → **Приложения** → **Дополнительные параметры приложений** → **Псевдонимы выполнения приложений**. Прокрути **в самый низ**: две строки **App Installer** (или **Установщик приложения**) — `python.exe` и `python3.exe`. Переключи обе в **Откл.**
4. Открой переменные среды (как в шаге 2), выбери **Path** в верхнем блоке → **«Изменить…»**.
5. Если строк с `Python314` нет — нажми **«Создать»** и добавь по очереди:
   ```
   %LOCALAPPDATA%\Programs\Python\Python314\
   ```
   ```
   %LOCALAPPDATA%\Programs\Python\Python314\Scripts\
   ```
6. Кнопкой **«Вверх»** подними обе строки **выше** строки `...\Microsoft\WindowsApps`. Это обязательно: даже с выключенными переключателями Windows может оставить заглушку на месте.
7. **OK** во всех окнах. Открой **новое** окно PowerShell и введи:
   ```
   python --version
   ```

**Должно получиться:** `Python 3.14.x`, без открытия Microsoft Store.

## Шаг 4. Node.js
1. В PowerShell:
   ```
   winget install --id OpenJS.NodeJS.LTS -e
   ```
2. Закрой PowerShell, открой новый и проверь:
   ```
   node --version
   ```

**Должно получиться:** `v24.x` или новее.

## Шаг 5. gdtoolkit
1. В PowerShell:
   ```
   pip install gdtoolkit==4.5.0
   ```
2. Проверь:
   ```
   gdlint --version
   ```

**Должно получиться:** `gdlint 4.5.0`.

Без флага `--user`: иначе программы лягут в папку, которой нет в Path.

## Шаг 6. Подключить MCP-сервер Godot
1. **Полностью закрой** приложение Claude (и VS Code, если Claude Code открыт там) и запусти заново — так они увидят новые переменные.
2. Открой проект `the-menders-tale` в Claude Code.
3. Claude спросит, разрешить ли MCP-серверы из `.mcp.json` проекта. Разреши сервер **godot**.

**Должно получиться:** в списке MCP-серверов (команда `/mcp` в Claude Code) есть **godot** со статусом connected.

## Шаг 7. Проверить
Напиши Claude:
```
Узнай версию Godot через MCP и сделай скриншот сцены прилавка из sandbox по tools/README.md.
```

**Должно получиться:** Claude отвечает `4.7.2` и показывает картинку прилавка.

## Частые проблемы
- **Открывается Microsoft Store вместо Python** → не выполнены пункты 3 или 6 шага 3; окно PowerShell старое — открой новое.
- **`python`/`gdlint`/`node` — «не является внутренней или внешней командой»** → не перезапущено окно или приложение; не добавлены строки в Path (шаг 3, пункт 5).
- **`gdlint` установился, но не находится** → ставил с `--user`. Выполни `pip uninstall -y gdtoolkit`, затем шаг 5 заново.
- **Сервер godot в `/mcp` — failed** → не задан `GODOT_PATH` или путь с опечаткой (шаг 2); приложение Claude не перезапущено после шага 2.
- **«Could not find a valid Godot executable»** → `GODOT_PATH` указывает не на `.exe` или на версию без `_console`. Проверь путь.
- **Окно Godot мелькает, когда Claude делает скриншот** → так и должно быть: для снимка Godot отрисовывает кадр на пару секунд.
