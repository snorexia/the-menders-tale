# С чего начать

Инструкции для участников команды The Mender's Tale. Проходи файлы по порядку — каждый шаг расписан: что нажать, какую команду ввести, что должно получиться. Непонятное слово — в [словарике](glossary.md).

## Порядок

| № | Файл | Что сделаешь | Кому |
|---|---|---|---|
| 1 | [01-install-tools.md](01-install-tools.md) | Установишь программы | Всем |
| 2 | [02-github.md](02-github.md) | Получишь доступ к репозиторию, скачаешь проект, войдёшь в GitHub CLI | Всем |
| 3 | [03-claude-code.md](03-claude-code.md) | Настроишь Claude Code и узнаешь, как давать ему задачи | Всем |
| 4 | [04-blender-mcp.md](04-blender-mcp.md) | Подключишь Blender к Claude | Дизайнеру, разработчику |
| 5 | [05-daily-workflow.md](05-daily-workflow.md) | Узнаешь, как работать каждый день: задача → план → PR | Всем |
| — | [glossary.md](glossary.md) | Словарик терминов | Всем |

Настройка ПК (шаги 1–4) делается один раз, примерно за час.

## Что прочитать, чтобы работать с Claude
1. [README проекта](../../README.md) — что за игра и где что лежит.
2. [docs/process/workflow.md](../process/workflow.md) — этапы, роли, задачи, ветки — коротко.
3. [05-daily-workflow.md](05-daily-workflow.md) — как проходит работа над задачей.

Сами правила для ИИ (`CLAUDE.md`, `.claude/rules/`) читать не обязательно — их читает агент. Но если хочешь понять, как он думает, начни с `CLAUDE.md`.

## Если что-то не получается
1. Посмотри раздел «Частые проблемы» в конце нужной инструкции.
2. Спроси Claude Code: «Не получается шаг N из docs/onboarding/02-github.md, вот ошибка: …».
3. Не помогло — напиши в общий чат и укажи, на каком шаге застрял.

Нашёл ошибку в инструкции или шаг устарел — скажи Claude, он поправит инструкцию через PR.
