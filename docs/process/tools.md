# Инструменты

Что используем и зачем. Как установить и настроить — пошагово в [docs/onboarding/](../onboarding/README.md).

| Инструмент | Зачем | Кому |
|---|---|---|
| Godot Engine 4.7.2 | Сцены, интерфейс, механики, запуск игры | Всем |
| GitHub Desktop | Получать и отправлять изменения без терминала | Всем |
| Git for Windows + Git LFS | Версии, крупные файлы, работа агентов | Всем |
| GitHub CLI (`gh`) | Задачи и PR из Claude Code | Всем |
| GitHub Issues + Projects | Задачи, обсуждения, проверка | Всем, в браузере |
| Claude Code | Работа с репозиторием через Claude: код, правила, задачи | Всем |
| Codex / GPT | Арт, генерация изображений | Дизайнеру |
| Godot MCP (Coding-Solo, `.mcp.json`) | Claude запускает Godot-проект, читает ошибки, создаёт сцены | Разработчику; остальным — по желанию |
| Python 3.14 + gdtoolkit | Проверка стиля GDScript (`gdlint`), вспомогательные скрипты | Разработчику |
| Node.js LTS | Нужен для MCP-сервера Godot | Разработчику |
| Blender + MCP for Blender | Модели, материалы, анимации; управление Blender из Claude | Дизайнеру, разработчику |
| Krita | Фоны, портреты, иконки, текстуры | Дизайнеру |
| VS Code | Код, тексты, документация | Разработчику, сценаристу |
| Генерация 3D (Meshy или другой — не выбран) | Модели по концепту | Дизайнеру |
| Discord или Telegram | Общение, созвоны | Всем |

Плагины для Godot и другие дополнения выбираем после этапа архитектуры — отдельной задачей.

## Что не попадает в репозиторий
В файлах проекта нет абсолютных путей, имён ПК, логинов и ключей. Всё личное — только в `CLAUDE.local.md` у каждого своё (файл в `.gitignore`).
