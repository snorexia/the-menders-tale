# Инструменты

| Инструмент | Зачем | Кому |
|---|---|---|
| Godot Engine | Сцены, интерфейс, механики, запуск игры | Всем |
| GitHub Desktop | Получать и отправлять изменения без терминала | Всем |
| Git for Windows + Git LFS | Версии, крупные файлы, работа Claude Code | Всем |
| GitHub Issues + Projects | Задачи, обсуждения, проверка | Всем, в браузере |
| Blender | Модели, материалы, анимации | Дизайнеру, разработчику |
| Krita | Фоны, портреты, иконки, текстуры | Дизайнеру |
| VS Code | Код, тексты, документация | Разработчику, сценаристу |
| Meshy | Генерация 3D (когда понадобится) | Дизайнеру |
| Claude Code | Работа с репозиторием через Claude | Всем |
| Discord или Telegram | Общение, созвоны | Всем |

Плагины для Godot и другие дополнения выбираем после этапа архитектуры — отдельной задачей.

## Настройка ПК (один раз)
1. Установить инструменты из таблицы.
2. В терминале: `git lfs install`.
3. GitHub Desktop → **Clone repository** → `snorexia/the-menders-tale`. Папку выбирай любую.
4. Установить Claude Code и запускать его в папке репозитория.
5. Для работы с задачами из Claude Code: `winget install GitHub.cli`, затем `gh auth login` (вход через браузер, ключи не нужны).
6. Blender + Claude — нужны две половинки **одного** проекта MCP for Blender (ahujasid):
   - аддон в Blender; сервер запускается в 3D-окне: `N` → вкладка MCP → Start (порт 9876);
   - сервер для Claude Code — пакет `blender-mcp` с PyPI (`uv tool install blender-mcp`), прописанный в MCP-настройках Claude Code.

   Официальный Blender Lab MCP с этим аддоном не работает — не смешивай их.
7. Личные заметки о своём ПК (путь к репозиторию, установленные версии, особенности настройки) — в `CLAUDE.local.md` в корне репозитория. Файл в `.gitignore` и в git не попадает.

## Что не попадает в репозиторий
В файлах проекта нет абсолютных путей, имён ПК и личных настроек. Всё это — только в `CLAUDE.local.md` у каждого своё.
