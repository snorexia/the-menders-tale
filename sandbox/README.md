# Песочница Godot (одноразовая)

> **Это не игра и не её архитектура.** Пробный проект для обучения и проверки инструментов агента (задача #12). Архитектура игры решается в #4; настоящий проект Godot создаётся на этапе 3 — отсюда можно что-то перенести, но не обязательно.
> Фоны — копии мокапов из `docs/reference/mockups/`: **не утверждённый арт**, в игру не идут. Исключение «мокапы в проекте» действует только для этой папки.

## Что внутри
- `scenes/counter/` — прилавок (фон `01-counter-customer.png`), кнопка «◀ В кузню».
- `scenes/forge/` — кузня (фон `02-forge-overview.png`), кнопка «К прилавку ▶».
- `common/scene_link_button.gd` — кнопка, открывающая другую сцену.

Без персонажей, мини-игр и сюжета — только внешний вид.

## Как открыть
1. Запусти Godot 4.7.2 → **Import** → выбери `sandbox/project.godot` → **Import & Edit**.
2. Нажми **F5** (Run Project) — откроется прилавок. Кнопками переходи между сценами.

Агенту: проверить без окна — `"$GODOT_PATH" --headless --path sandbox --quit`; скриншот сцены — `tools/godot_screenshot.gd` (см. `tools/README.md`).
