# Песочница «2D-слои» (layers-2d)

> Одноразовая, не игра и не архитектура — см. `sandbox/README.md`.

Вариант: **мокап, разрезанный на слои**, камера **осматривает комнату** за мышью (картинка крупнее экрана и сдвигается целиком), плюс мерцающий свет и огонь. Задача #15.

> Сначала слои сдвигались с разной силой (параллакс). Человек отверг: дальний слой — весь мокап, и сдвинутый предмет оставлял за собой свою нарисованную копию. Теперь все слои двигаются вместе; они разделены, чтобы в будущем ставить персонажа между ними.

## Что внутри
- `scenes/counter/` — прилавок (мокап `08-counter-empty.webp`): 3 слоя, 2 фонаря и 3 свечи мерцают, кнопка «◀ В кузню».
- `scenes/forge/` — кузня (мокап `07-forge-empty.webp`): 4 слоя, 2 лампы мерцают, огонь горна (пламя, искры, свет), кнопка «К прилавку ▶». Наковальня кликабельна (#22): при наведении светлеет, курсор — рука, клик открывает крупный план. Горн тоже (#28): клик открывает крупный план горна. Подсветка горна — узел `Hearth` (`Polygon2D` с текстурой `forge_sides.png` по контуру горна), без отдельного PNG.
- `scenes/anvil/` — крупный план наковальни сверху (#22) с **мини-игрой ковки** (#25): по заготовке по очереди сжимаются круги, кликни, когда круг сожмётся и посветлеет (рано, мимо или не успел — не засчитано). 3 стадии по 5 кругов, фон каждой — картинка дизайнера `anvil_stage_1..3.webp` (заготовка → полоса → клинок). В конце — качество меча: все попадания — высокая рарность, от 75 % — хорошее, от 50 % — плохое, ниже — мусор; «Ещё раз» или «◀ В кузню». Назад в любой момент — кнопка, Esc или правый клик. Скрипты: `anvil.gd` (ход игры), `strike_ring.gd` (круг). Прежняя заглушка (`anvil_metal/wood/floor.png`, `anvil_textures.json`) и рендер меча `longsword_top.png` в сцене больше не используются.
- `scenes/hearth/` — крупный план горна с **мини-игрой нагрева** (#28), фон — картинка дизайнера `hearth_background.webp`. Держи левую кнопку мыши или пробел — заготовка греется (металл краснеет → оранжевеет → желтеет, свечение, у самого перегрева искры), отпустил — остывает. Отпустил в зелёной рамке шкалы — «хорошо», в жёлтой (середина) — «идеально», ниже — грей дальше, выше рамки или до 100 % — мусор. Скрипт — `hearth.gd`.
- `source/longsword_trial.glb` — 3D-модель меча от дизайнера (исходник для рендера; `.gdignore` — Godot её не импортирует).
- Слои сцены: `*_back` (весь мокап) → `*_sides` (мебель по бокам, горн) → `forge_anvil` (только в кузне) → `*_front` (прилавок, бочка, ящики). Каждый — PNG на весь холст, прозрачный вне вырезанной части.
- `scenes/<сцена>/<сцена>_layers.json` — многоугольники слоёв в пикселях мокапа (из них `tools/cut_layers.py` делает PNG).
- `common/mouse_look_camera.gd` — камера сдвигается за мышью (до 110×60 px): мышь у края — видна та часть комнаты. Картинка увеличена в 1.3 раза, чтобы за краем экрана был запас.
- `common/flicker_light.gd` — свет (`PointLight2D`), яркость и размер которого гуляют по шуму.
- `common/light_glow.tres` — мягкое круглое пятно: текстура для света и частиц огня.
- `common/scene_link_button.gd` — кнопка, открывающая другую сцену (копия из `backdrop`); с `Is Back Button` срабатывает ещё по Esc и правому клику.
- `common/scene_link_area.gd` — область на картинке (`Area2D` + многоугольник), открывающая сцену по клику, с курсором-рукой и подсветкой.

## Как открыть
1. Запусти Godot 4.7.2 → **Import** → выбери `sandbox/layers-2d/project.godot` → **Import & Edit**.
2. Нажми **F5** (Run Project) — откроется прилавок. Поводи мышью к краям окна — камера осматривает комнату. Кнопками переходи между сценами.

## Что подкрутить
- **Размах осмотра** — у узла `Camera` в сцене: `Max Offset` (сейчас 110×60 px) и `Follow Speed`. Больше 120×70 нельзя — откроется край картинки; нужен больший размах — увеличь `Scale` у всех `Sprite` слоёв и пересчитай их `Position`.
- **Темнота сцены** — цвет узла `Darkness` (`CanvasModulate`).
- **Мерцание** — у каждого света: `Strength`, `Scale Strength`, `Speed`; яркость — `Energy`, размер пятна — `Texture Scale`.
- **Огонь** — узлы `Flames` и `Sparks` в кузне (`CPUParticles2D`).
- **Мини-игра ковки** — у корня `Anvil` в сцене `scenes/anvil/anvil.tscn`: `Rings Per Stage` (кругов на стадию), `Strike Area` (где появляются круги), группа **Круг** (размер, время сжатия, `Ring Hit From` — с какой доли сжатия бить можно), группа **Качество** (пороги и названия), группа **Тексты**.
- **Мини-игра нагрева** — у корня `Hearth` в `scenes/hearth/hearth.tscn`: `Heat Speed` и `Cool Speed` (скорость нагрева и остывания), зоны `Good From/To` и `Perfect From/To`, `Sparks From`; группа **Вид** — градиенты цвета металла (`Metal Gradient`) и свечения (`Glow Gradient`); группа **Тексты**.

## Как перерезать слои
Поправь многоугольники в `scenes/<сцена>/<сцена>_layers.json` и из корня репозитория запусти:
```
python tools/cut_layers.py sandbox/layers-2d/scenes/counter/counter_layers.json --preview counter_preview.png
```
`--preview` сохранит мокап с контурами слоёв — проверить нарезку глазами (файл не коммить).

## Как перерендерить меч
Из корня репозитория (окно Godot мелькнёт):
```
"$GODOT_PATH" --path sandbox/layers-2d --script "$(pwd -W)/tools/render_model.gd" -- "$(pwd -W)/sandbox/layers-2d/source/longsword_trial.glb" "$(pwd -W)/sandbox/layers-2d/scenes/anvil/longsword_top.png" 1180 -90
```
1180 — пикселей на метр (тот же масштаб, что у наковальни в крупном плане), −90 — поворот, чтобы остриё смотрело вправо.

Агенту: проверить без окна — `"$GODOT_PATH" --headless --path sandbox/layers-2d --quit-after 5`; скриншот сцены — `tools/godot_screenshot.gd` (см. `tools/README.md`).
