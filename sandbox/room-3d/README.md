# Песочница «3D-комната» (room-3d)

> Одноразовая, не игра и не архитектура — см. `sandbox/README.md`.

Вариант: **настоящее 2.5D** — комнаты из простых 3D-блоков (greybox — «серые коробки»), на блоках — текстуры, которые нарисовал агент. Свет и тени настоящие, камера чуть поворачивается за мышью. Задача #16.

## Что внутри
- `scenes/counter/` — прилавок (по мокапу `08-counter-empty.webp`): фонари, свечи, коврик на прилавке, кнопка «◀ В кузню».
- `scenes/forge/` — кузня (по мокапу `07-forge-empty.webp`): горн с огнём и искрами (огонь светит и отбрасывает тени), две лампы, кнопка «К прилавку ▶».
- `textures/` — 7 бесшовных текстур (камень, плитка, кирпич горна, доски, балки, металл, коврик). Нарисованы скриптом `tools/make_textures.py`: цвета взяты с мокапов, узор процедурный (по правилам, без нейросетей).
- `materials/` — общие материалы. Текстуры наложены **triplanar** (проецируются по мировым осям): блок любого размера получает текстуру без растяжения.
- `common/` — `camera_sway.gd` (поворот камеры за мышью, ±2°), `flicker_light_3d.gd` (мерцание огня и свечей), `scene_link_button.gd` (кнопка перехода).

Каждый предмет — встроенный меш (`BoxMesh`, `CylinderMesh`), размер задан масштабом узла. Без моделей из Blender, персонажей, мини-игр и звука.

## Как открыть
1. Запусти Godot 4.7.2 → **Import** → выбери `sandbox/room-3d/project.godot` → **Import & Edit**.
2. Нажми **F5** (Run Project) — откроется прилавок. Подвигай мышью — камера чуть повернётся, видно объём. Кнопками переходи между сценами.

Нужна видеокарта с Vulkan (рендер Forward+).

## Перерисовать текстуры
```
python tools/make_textures.py --out sandbox/room-3d/textures
```
Нужен Pillow — `docs/onboarding/07-godot-tools.md`, шаг 5.

Агенту: проверить без окна — `"$GODOT_PATH" --headless --path sandbox/room-3d --quit-after 5`; скриншот сцены — `tools/godot_screenshot.gd` (см. `tools/README.md`).
